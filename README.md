# Portfolio · Santiago Fernandez

Mi portfolio personal como desarrollador frontend junior.

**Sitio:** https://santiagofernandez346.github.io/portafolio-2/

## Qué tiene

- Presentación, proyectos destacados, habilidades, experiencia y contacto.
- **Español e inglés**, con el idioma recordado entre visitas (y el CV correspondiente para descargar).
- **Modo claro y oscuro**, que respeta la preferencia del sistema.
- Diseño adaptable a celular, navegación accesible con teclado y animaciones que se desactivan si el usuario prefiere menos movimiento.

## Tecnologías

HTML, CSS y JavaScript sin frameworks ni dependencias, publicado con GitHub Pages.

## Estructura

```
index.html              Contenido (en español)
assets/css/styles.css   Estilos, tema claro/oscuro y responsive
assets/js/main.js       Traducción al inglés, tema, menú y animaciones
assets/img/             Foto y capturas de los proyectos
assets/files/           CV en español e inglés (PDF)
```

## Verlo en local

Abrí `index.html` en el navegador, o levantá un servidor estático en la carpeta (por ejemplo `npx serve`).
